# Итоги Stage65A

## Классификация

`stage65a-blocked-repository-access-local-release-candidate-complete`

Локальный кандидат релиза `XSlim 2.1.2+riscy.1` полностью подготовлен и
проверен. Публичный форк и GitHub Release не созданы: GitHub дважды вернул
HTTP 403 для токена, которым выполнен вход. Создавать вместо форка отдельный
несвязанный репозиторий нельзя, потому что это нарушило бы условия этапа.

Основа зафиксирована на upstream-коммите
`9a33f2f770d00fd02ff8bc0f1907135e9bf47f8c`. Исправление обработки
двухвходового ReduceMax уже было в upstream и не приписывается RISCY-SVT.

Добавлено:

- расширенное покрытие ReduceMax, включая пустые оси и пустые тензоры;
- отдельная опциональная проверка выходов YOLO;
- отдельный аудит диапазонов и насыщения на границах Q/DQ;
- безопасный пример шестивыходного разбиения YOLO26;
- сведения об upstream, модификациях, лицензиях и неофициальном статусе.

Полный набор тестов: 140 успешно, 7 предупреждений, 65 подтестов успешно.
Ruff, компиляция Python, ограниченная проверка mypy для новых инструментов,
установка wheel/sdist в чистые окружения и `pip check` прошли.

Прямой E2E-путь YOLO26 по-прежнему непригоден: оценки объектов обнулились на
100 из 100 контрольных изображений. Исправление YoloDecode не вносилось,
поскольку причинная связь не была доказана узким публичным примером.
Проверенным остается путь с шестью раздельными выходами.

Wheel и нормализованный sdist воспроизводимы побайтно. Архивы содержат
Apache-2.0, необходимые уведомления и SBOM; моделей, весов, ORT, калибровочных
изображений и закрытых данных в них нет.

Для завершения публикации человеку нужно выдать учетной записи право создавать
форки в организации `RISCY-SVT`, обновить токен GitHub CLI и повторить точную
команду из `human_decision_options.md`. Stage65B не запускался.
